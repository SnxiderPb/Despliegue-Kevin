Despliegue Automatizado con Ramas y Pull Requests

Una de las mayores ventajas de conectar GitHub con Vercel es el despliegue continuo: Vercel vigila tu rama principal (main) y actualiza tu web en vivo cada vez que recibe código nuevo.

1

Crear una Rama Secundaria

En lugar de editar directamente sobre main, crea una rama nueva (ej. rama-ejemplo). Haz tus modificaciones en el código, guarda un commit y publícala en GitHub. Tu sitio en producción seguirá intacto.

2

Abrir un Pull Request (PR)

Entra a tu repositorio en GitHub, ve a la pestaña Pull Requests y crea una solicitud para comparar y llevar los cambios desde rama-ejemplo hacia main.

3

Merge y Re-despliegue Automático

Revisa los cambios y haz clic en Merge pull request. Al instante, Vercel detectará la actualización en main, ejecutará un nuevo build y actualizará tu página pública con la etiqueta Current.
