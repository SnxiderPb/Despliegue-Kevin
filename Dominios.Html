Dominios Personalizados, Subdominios y Analytics

1. Conectar un Dominio Propio y Subdominios

Ve a tu proyecto en Vercel > Settings > Domains, escribe tu dominio (ej. midominio.com) y agrega los siguientes registros en la configuración DNS de tu proveedor (Squarespace, GoDaddy, Namecheap, etc.):

Uso Tipo Nombre / Host Valor / Apunta a
Dominio raíz (midominio.com) A @ 76.76.21.21 (IP indicada por Vercel)
Versión con WWW (www.midominio.com) CNAME www cname.vercel-dns.com
Subdominio (ej. blog.midominio.com) A / CNAME blog Se asigna desde la pestaña Domains de Vercel

2. Activar Vercel Analytics (Gratis)

Para medir visitantes únicos, vistas de página (Page Views) y origen del tráfico (Referrers):

  1. En tu proyecto de Vercel, abre la pestaña Analytics y haz clic en Enable (plan gratuito).
  2. Instala la librería en tu proyecto local: 
    npm i @vercel/analytics
  3. Importa el componente en tu archivo principal (ejemplo en Next.js app/layout.js) y súbelo a GitHub: 
    import { Analytics } from '@vercel/analytics/next';

export default function RootLayout({ children }) {
  return (
    <html lang="es">
      <body>
        {children}
        <Analytics />
      </body>
    </html>
  );
}
