Despliegue de un Proyecto Básico (HTML, CSS y JS)

Si tienes una página web estática (por ejemplo, una carpeta src con index.html, styles.css y script.js), sigue estos dos pasos para publicarla en internet.

Paso A: Subir el proyecto a GitHub

  1. Crea una cuenta en github.com y haz clic en New Repository.
  2. Asígnale un nombre, déjalo como Público o Privado y créalo.
  3. Abre la terminal en Visual Studio Code dentro de la carpeta de tu proyecto y ejecuta:
git init
git add .
git commit -m "First commit"
git branch -M main
git remote add origin https://github.com/tu-usuario/tu-repo.git
git push -u origin main
Alternativa visual: Si prefieres no usar comandos, instala GitHub Desktop, inicia sesión, agrega tu carpeta local (Add Existing Repository), escribe un mensaje de commit y presiona Push origin.

Paso B: Conectar y Desplegar en Vercel

  1. Entra a vercel.com e inicia sesión directamente con tu cuenta de GitHub.
  2. Haz clic en Add New > Project y selecciona Import junto a tu repositorio.
  3. En Framework Preset, deja la opción Other (al ser HTML/CSS/JS puro).
  4. Importante: Si tu index.html no está en la raíz sino dentro de una carpeta (ej. src), edita el campo Root Directory y selecciona esa carpeta.
  5. Haz clic en Deploy. En segundos obtendrás tu enlace público .vercel.app.
