Proyectos con Frameworks y Variables de Entorno

Cuando importas un proyecto desarrollado con Next.js, React (Vite), Vue, Angular o Astro, Vercel detecta el framework automáticamente y configura los comandos de compilación.

Configurar Variables de Entorno (Environment Variables)

Por seguridad, el archivo local .env está ignorado en Git (.gitignore) y nunca debe subirse a GitHub. Para que tu aplicación funcione en Vercel:

  1. En la pantalla de configuración previa al despliegue en Vercel, despliega la sección Environment Variables.
  2. Abre tu archivo .env local, copia todas las líneas (claves de API, URLs de bases de datos, secretos) y pégalas en el primer campo de Vercel; la plataforma separará automáticamente los nombres y valores.
  3. Presiona Deploy para iniciar el proceso de compilación (Build).

¿Qué hacer si falla el Build?

Vercel ejecuta una compilación estricta antes de publicar. Si tienes errores de tipado en TypeScript o importaciones rotas, el despliegue se detendrá y te mostrará la ruta exacta y el número de línea del fallo en los logs. Corrige el error en tu editor, haz commit y push a main para que Vercel intente desplegar nuevamente.
